# Finished Product

Keep creator commentary out of the product.

| Skill | Use |
| --- | --- |
| [finished-product](skills/finished-product) | No creator commentary or filler in anything people see |
| [show-dont-write](skills/show-dont-write) | Interfaces that show information instead of writing it |
| [tables](skills/tables) | Tables people can read and use |
| [charts](skills/charts) | Charts that answer one question honestly |

`finished-product` stands alone. Add the others for UI work.

Download this repo and copy the skill folders you want to the location below. To apply the base rule by default, also paste [RULES.md](RULES.md) into the last column.

| Harness | Skill folders | Persistent instructions |
| --- | --- | --- |
| [Codex](https://learn.chatgpt.com/docs/build-skills) | `~/.agents/skills/` | [`~/.codex/AGENTS.md`](https://learn.chatgpt.com/docs/agent-configuration/agents-md) |
| [Claude Code](https://code.claude.com/docs/en/skills) | `~/.claude/skills/` | [`~/.claude/CLAUDE.md`](https://code.claude.com/docs/en/memory) |
| [Cursor](https://cursor.com/docs/skills) | `~/.cursor/skills/` | [Customize → Rules → User Rules](https://cursor.com/docs/rules) |

Keep existing instructions; append the rule. Start a new session.

For other harnesses, paste RULES.md into their persistent instructions or system prompt.
