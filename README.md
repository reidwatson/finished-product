# Finished Product

Keep creator commentary out of the product.

Download this repo and copy [the skill folder](skills/finished-product) to the location below. To apply it by default, also paste [RULES.md](RULES.md) into the last column.

| Harness | Skill folder | Persistent instructions |
| --- | --- | --- |
| [Codex](https://learn.chatgpt.com/docs/build-skills) | `~/.agents/skills/finished-product` | [`~/.codex/AGENTS.md`](https://learn.chatgpt.com/docs/agent-configuration/agents-md) |
| [Claude Code](https://code.claude.com/docs/en/skills) | `~/.claude/skills/finished-product` | [`~/.claude/CLAUDE.md`](https://code.claude.com/docs/en/memory) |
| [Cursor](https://cursor.com/docs/skills) | `~/.cursor/skills/finished-product` | [Customize → Rules → User Rules](https://cursor.com/docs/rules) |

Keep existing instructions; append the rule. Start a new session.

For other harnesses, paste RULES.md into their persistent instructions or system prompt.
